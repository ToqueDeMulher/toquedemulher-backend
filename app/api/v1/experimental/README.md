# Experimental endpoints

Estes módulos foram mantidos para referência, mas não são registrados em
`app.main` e não fazem parte da API ativa.

Eles dependem de modelos/schemas que ainda não existem ou que não batem com a
camada atual baseada em SQLModel. Antes de promover qualquer arquivo daqui para
`app/api/v1/endpoints/`, ajuste os imports, schemas, testes e chamadas do
frontend correspondentes.
